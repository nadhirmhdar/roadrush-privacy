# Privacy Policy — Road Rush: Four Worlds

**Effective date:** 16 October 2026
**App:** Road Rush: Four Worlds (`com.grovisor.roadrush`), published by Grovisor.

## The short version
This game collects **no personal data, no usage data — no data at all.**

## Details
- **No network access.** The app declares no INTERNET permission, so the operating
  system itself prevents it from sending or receiving anything online.
- **No data collection.** We do not collect, store, transmit, sell or share any
  personal information, identifiers, usage analytics, crash reports, location data
  or advertising IDs.
- **No accounts.** There is no registration, login or profile.
- **No third-party SDKs.** The app contains no advertising, analytics, tracking or
  social SDKs of any kind.
- **Motion sensor.** If you choose tilt steering, accelerometer readings are used
  on-device, in the moment, purely to steer the car. They are never recorded or
  transmitted, and touch controls are always available instead.
- **Local save data.** Your scores, coins, unlocks and settings are stored only on
  your device, in the app's private storage. Uninstalling the app deletes them.
- **Children.** The game is suitable for general audiences and, collecting no data,
  processes no data from children.

## Changes
If a future version ever changes any of the above, this policy and the Play Store
Data safety section will be updated before that version ships.

Questions: contact the developer via the email address listed on the app's
